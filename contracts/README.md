# FloatSheets contracts

This is a Foundry workspace for prospective FloatSheets contracts on Robinhood Chain (chain ID `4663`). No protocol contract is implemented or deployable yet.

The initial product scaffold treats direct Uniswap V3 stock/USDG pools as market-depth references while a future contract design is decided. Do not deploy from this directory until that design, audit scope, oracle model, and custody model are agreed.
